# Machine Learning Project (Brain Tumor Classifier)
Machine Learning project to recognise 4 types brain tumors (glioma, meningioma, no tumor and pituitary) based on MRI images.

# To run
Run `pip install -r requirements.txt`
<br></br>
In app.py, replace line 10 with path for image of your choice
<br></br>
Run `python app.py`
